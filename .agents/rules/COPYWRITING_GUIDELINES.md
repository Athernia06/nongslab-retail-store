# Copywriting rulebook

Read when writing or editing any user-facing text: labels, buttons, empty states, errors, toasts.

## Voice

- Plain, direct, specific. "Cart is empty" not "Your shopping journey begins here".
- No marketing fluff, no exclamation marks, no emoji, no hype words ("amazing", "blazing", "supercharge").

## Rules

- Buttons start with a verb: "Add to cart", "Clear filters", "Checkout".
- Empty states name the absence and the action: "No products match these filters. Clear filters to see everything."
- Errors say what failed and what to do: "Payment failed. Try another card."
- Sentence case everywhere. No ALL CAPS except single-accent words if the design already uses them.
- Numbers are local-formatted; currency uses the currency symbol appropriate to the locale, never invented notation.
- One line per message where possible; two maximum. No paragraphs in UI copy.
